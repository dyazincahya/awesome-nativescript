# Octane Example of NativeScript

This directory contains examples demonstrating the use of NativeScript with Octane (an ahead-of-time compiled React replacement library). These examples showcase how to build native mobile applications using the Octane framework.

| Name | Description | Platform | Author | Source | Link |
| --- | --- | --- | --- | --- | --- |
| `ns-octane` | A NativeScript app rendered by Octane. No React, no virtual DOM, no DOM shim. NativeScript example project showcasing the ahead-of-time compiled Octane framework with SwiftUI integration and Tailwind CSS. | Android & iOS | [Nathan Walker](https://github.com/NathanWalker) | Github | [View](https://github.com/NathanWalker/ns-octane) |
